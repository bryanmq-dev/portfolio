## Un portafolio que no se lee: se recorre

No hay menús ni plantillas. Al entrar, mi nombre se escribe letra por letra en el centro de una red viva de nodos que reacciona a tu cursor. Cada nodo es una puerta: al abrirla, **toda la red se transforma** en lo que vas a ver.
